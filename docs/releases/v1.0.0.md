# SVNRevDesk v1.0.0

首次公开发布：面向 Windows 的中文 SVN 版本工作台。

## 下载选择

两个版本**功能完全相同**，均内置 SVN 1.14.5 和 WinMerge 2.16.58.2。

| 文件 | 说明 |
| --- | --- |
| `SVNRevDesk-v1.0.0-win-x64-with-runtime.zip` | **自带运行时版**：无需另外安装 .NET，解压即用。 |
| `SVNRevDesk-v1.0.0-win-x64-without-runtime.zip` | **不带运行时版**：需安装 .NET 10 Desktop Runtime（Windows x64）。 |
| `SHA256SUMS.txt` | 两个 ZIP 的 SHA-256 校验值。 |

支持 Windows 10 / 11 x64。将 ZIP 完整解压到可写文件夹后，运行 `SVNRevDesk.exe`。文件大小见下方 Assets。

## 主要功能

- 本地工作副本和仓库 URL 浏览、关联 / 完整 / 稀疏检出。
- 目录树、列表 / 卡片视图，文件状态、修订号、锁定信息与差异筛选。
- 与服务器、BASE、历史版本比较，可选图片与文本预览。
- 勾选提交、更新、导出、历史、锁定、冲突处理、分支 / 标签、切换与合并。
- 文件复制、剪切、粘贴、拖放、保留 SVN 历史的移动及新建 Office 文档。
- 仅本机忽略、缓存优先启动、浏览位置恢复、备份管理与系统托盘。

## 使用提示

- 首次使用 SVN 或比较工具时，将在程序旁释放 `Tools` 文件。
- 设置、缓存、备份和 SVN 配置保存在程序目录；本机忽略规则保存在当前 Windows 用户配置中。
- 升级前退出程序，保留已有设置和数据目录。
- 自动化测试使用本地真实 SVN 仓库；特定服务器、认证方式及 Office 转换插件需按实际环境验证。
- 当前内置 SVN 命令行受 Windows 系统代码页限制。中文路径已在中文区域环境验证；英文 Windows 环境建议使用英文目录和文件名。
