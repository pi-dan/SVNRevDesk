# SVNRevDesk v1.6.0

重启恢复仓库时优先显示本地文件，改善慢网下的浏览和登录体验。

## 本次更新

- 重启时即使浏览缓存缺失或损坏，也先显示本地文件和上次目录，再在后台恢复服务器状态；失败或取消保留本地列表。
- 修复后台目录读取完成后列表仍停留在本地预览的问题。
- 登录支持“记住密码”，使用 Windows 当前用户加密保存，重启后自动恢复；取消勾选并确认可清除保存的凭据。
- 登录后自动刷新当前目录；后台认证失败时提示登录并重试，取消或密码错误时避免反复弹窗。
- 左侧选择目录时仅展开当前目录，收起其下已展开的子目录。
- 支持 Backspace 返回上一级目录，输入框内仍用于删除字符。
- 详细列表将“提交人”移到“服务器修改时间”后，移除“本地最后修改”和“本地基础版本”列。
