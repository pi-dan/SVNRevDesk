# SVNRevDesk v1.1.0

偏向文件管理的 Windows 中文 SVN 客户端，适合在 SVN 仓库中整理文档、办公文件和设计素材等共享资料。本次新增多仓库页签，以及围绕文件和文件夹的历史版本选择、更新与回滚。

## 本次更新

- **多仓库同时打开**：每个工作副本或仓库 URL 使用独立页签，分别保留目录、筛选和选择。支持 Ctrl+Tab 切换、Ctrl+W 关闭，重启后恢复打开的会话。
- **收藏与长期关联**：收藏常用位置，自动保存已验证的工作副本路径与仓库 URL，可从关联列表打开本地或在线仓库。
- **更新到指定修订号**：文件、文件夹和目录树目标均可使用；支持下拉选择、点击历史记录或手动输入修订号。
- **只显示目标的相关历史**：文件只列自身提交，文件夹包含子项变化；多选时合并并去重，排除其他文件和目录的无关提交。可查看提交人、时间和完整说明，筛选已加载记录，并继续加载更早历史。
- **预览后回滚单次提交**：使用反向合并撤销指定提交，执行前检查未提交修改并展示预览。回滚结果留在本地，检查差异、解决冲突后再手动提交。

## 升级与使用

- 升级前退出程序，保留原有 `settings.json`、`Cache`、`Backups`、`SvnConfig` 等设置与数据，再用新版程序文件替换；个人资料不会进入官方发布包。
- 首次使用 SVN 或比较工具时，会在程序旁释放 `Tools` 文件。
- SVN 修订号为整个仓库统一编号，目标历史中的编号可能不连续。手动输入修订号不受已加载列表限制。
- 更新或回滚会改变本地工作文件；回滚不会删除服务器历史或自动提交。请先处理未提交修改，并检查操作结果。
- 当前内置 SVN 的文件路径受 Windows 系统代码页影响；中文路径已在中文区域环境验证，英文 Windows 建议使用英文目录和文件名。
