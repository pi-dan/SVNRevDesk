# SVNRevDesk v1.5.0

首次进入目录时优先显示本地文件，避免网络较慢时长时间等待空白列表。

## 本次更新

- 未缓存的目录先读取本地文件并允许操作，服务器状态与目录列表在后台补齐。
- 服务器信息尚未返回时明确显示本地预览；网络失败保留本地列表，重新进入目录时重试。
- 快速切换目录时，旧请求不会覆盖当前文件列表；本地预览不会被误认为完整服务器缓存。
