# SVNRevDesk v1.7.0

增强文件和文件夹删除操作，删除前保留内容备份，并支持未下载的服务器项目。

## 本次更新

- 删除前备份全部现有文件内容，支持本地修改、冲突、阻塞、替换、缺失以及包含未受控文件的目录；自动处理只读文件。备份不包含 SVN 属性和调度信息。
- 支持删除未下载的文件和文件夹：先准备 SVN 信息，再登记待提交删除；文件可能临时下载，文件夹不递归下载。服务器内容仍需提交后才删除。
- 遇到上次 SVN 操作未完成或工作副本锁定（E155037 / E155004）时，自动清理一次、重新检查状态并重试；保留备份路径，失败时报告原因。
- 新增 `scripts/Build-SingleFile.ps1`，快速生成不带运行时的单文件程序，验证成功后才更新输出文件。
