# SVNRevDesk v1.3.0

本次更新加入界面内拖放移动，并改进当前目录操作和启动时的搜索索引检查。

## 本次更新

- 在文件列表中将本地文件或目录拖到文件夹，或拖到左侧目录树，即可移动到该目录。移动保留 SVN 历史，遇到同名项目时沿用现有冲突选择；完成后停留在原目录，不自动提交。外部文件拖入仍为复制。
- 当前路径旁新增复制本地路径和在资源管理器中打开当前目录按钮；不可用的本地目录会给出提示或禁用操作。
- 修复重启后搜索索引重复扫描整个工作副本的问题；手动刷新仍会检查本地变化。
- 详细列表将服务器修改时间和大小列放在状态列之后。
- 本地开发版和正式版统一采用三段式版本号。
