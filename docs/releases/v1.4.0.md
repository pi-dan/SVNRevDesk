# SVNRevDesk v1.4.0

修复首次打开需要登录的仓库时，界面仍显示“打开仓库，开始浏览”、看起来没有响应的问题。

## 本次更新

- 打开地址时遇到认证失败，自动弹出本次会话登录窗口；输入账号密码后自动重试，无需再次点击打开。
- 取消登录或账号密码不正确时，主界面保留明确的登录提示；其他打开错误会显示失败原因。
- 账号密码仅保存在本次会话内，不写入配置、日志或命令行；重试继续使用当前仓库页签。
