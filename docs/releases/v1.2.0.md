# SVNRevDesk v1.2.0

本次新增持久化跨目录搜索、独立历史浏览、批量重命名、文本冲突三方合并及“更新当前层文件”，并修复搜索索引后台任务的完成、恢复和重复排队问题。

## 本次更新

- **跨目录搜索**：默认搜索当前页签整个已打开范围，也可选择当前目录及子目录。首次建立本机持久化清单，后续输入即搜索；包含纯在线和稀疏副本中未下载的项目，支持刷新、重建及离线缓存。
- **直接打开搜索结果**：双击或按回车打开文件、进入文件夹；右键可定位到所在目录、在资源管理器中显示或复制路径。显示文件类型图标，未下载文件沿用主界面的版本选择。
- **索引后台核对修复**：文件更新完成后及时释放操作界面；只有实际被打断的索引任务才恢复，重复刷新请求合并，处理期间收到的新修订号也会继续核对，避免无关操作反复启动整份索引扫描。核对完成后提示自动消失，失败或取消时保留原缓存。
- **更新当前层文件**：主页工具栏一键更新当前目录的文件，无需选择、不受筛选影响，不更新子目录。空的稀疏目录可扩展到仅文件深度；保留本地修改，冲突留待处理，不自动提交。
- **独立历史浏览窗口**：按目标文件或目录读取相关提交，多选时去重；支持修订号、作者、时间及说明筛选，并可分页读取更早历史。
- **批量重命名**：支持名称替换、前后缀、编号及保留扩展名，实时预览并检查名称冲突；执行前复核 SVN 状态，保留移动历史与本地修改。
- **WinMerge 文本冲突合并**：读取基础、本地和本次冲突的服务器版本，在独立草稿中合并。用户确认后复核工作文件、写回并标记单个文本冲突为已解决，不自动提交；保留备份，检查遗留冲突标记和外部修改。此入口不处理二进制、属性或目录树冲突。

## 升级与使用

- 升级前退出程序，保留原有 `settings.json`、`Cache`、`Backups`、`SvnConfig` 等设置与数据，再替换程序文件。官方发布包不包含个人数据。
- 首次使用 SVN 或比较工具时，会在程序旁释放 `Tools` 文件。本次更新不自动向 SVN 服务器提交任何工作文件。
- 搜索索引保存在本机，各电脑、工作副本及账号分别缓存。服务器检查失败时仍可搜索上次清单，但可能尚未包含最新变化。
- 更新、批量重命名和解决冲突会改变本地工作文件；执行后请检查结果，再按需提交。
- 当前内置 SVN 的文件路径受 Windows 系统代码页影响；中文路径已在中文区域环境验证，英文 Windows 建议使用英文目录和文件名。
