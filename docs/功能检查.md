## 本次修复与改进

1. **目录 BASE 比较修正。** 原来“与基础版本比较”也调用 HEAD 比较；现在使用本地 BASE → 工作文件摘要。验证了远端单独修改不会混入 BASE 结果，且路径含中文、空格和 `@` 时正常。
2. **关联本地后保留目录。** 关联工作副本前校验仓库 UUID 和根目录 URL，关联成功后恢复正在浏览的子目录；不匹配时提示预期与实际 URL。
3. **按钮与菜单启用条件统一。** 没有选择项目、多选时仅支持单项的操作、未关联本地时的写操作、没有对应版本的比较等入口按条件禁用，SVN 服务仍负责实际命令校验。
4. **差异统计完善。** 文件夹本身没有变化、子项有变化时也计入差异项目。未关联本地的在线目录不计为确定差异；开启“只显示差异”时提示先关联本地，状态筛选继续保留带后代差异的目录。
5. **排序与筛选反馈。** 修订号列和时间列按数值 / 时间排序；显示可见项目数、总数与选择数，空目录、筛选无结果、读取中显示不同提示。
6. **本地修改通知保留。** 不再丢弃 SVN 操作期间收到的工作文件变化通知，空闲后进行合并刷新，减少外部编辑未及时显示的情况。
7. **UI 调整。** 浅色面板、圆角控件、浅蓝选中、状态标签、目录概要、精简路径信息；在线关联 / 检出入口置于当前目录区域；目录树长文本省略并提供完整提示。
8. **快捷键。** 地址框 Enter 打开，F5 刷新，Alt+↑ 返回上一级，文件列表 Enter 打开、Ctrl+D 比较。
9. **批量导出与便携存储。** 右键增加多选导出入口，以同一服务器快照下载，完成项目逐个发布、取消时清理未完成的临时目录。应用数据放在 EXE 旁，兼容迁移旧设置与 SVN 配置，备份也集中到程序目录。
10. **结果窗口与任务完成。** 文件比较启动外部工具后结束任务，历史记录、目录差异等结果窗口独立显示，查看结果不再阻塞任务结束，完成后进度条隐藏并停止计时；比较准备被取消时不启动工具。
11. **按范围刷新。** 将自动全范围检查和当前目录检查分开，文件操作只检查所在目录，递归目录操作只检查相关子树及所在列表。其他目录保留检查时间和版本；手动检查不重置自动检查计时。目录被删除时清除对应缓存，查询失败时保留旧结果。
12. **缓存优先启动。** 浏览数据保存在 EXE 旁的 `Cache`，现按会话隔离在 `Cache/Sessions/`，兼容原有 `Cache/browsing-session.json`；启动时先恢复目录、版本、状态与选择位置，服务器初始化改为可取消后台读取。缓存读取 / 解析不占用 WPF 线程，仅恢复展开和选中位置所需的目录树分支。本地先校验工作副本映射，防止切换 / 替换后的旧缓存混用；在线缓存先展示，再核对仓库身份。普通本地文件直接打开，不等待服务器初始化。首次安装或缓存不可用时仍通过后台初始化获取列表。
13. **勾选提交项目。** 提交所选 / 当前目录均使用独立提交窗口，实时读取本地变更，支持勾选、全选 / 取消全选、数量统计和可选提交说明。采用明确目标和 `--depth empty`，目录属性和新增目录不递归提交未勾选文件。新增父目录与子项联动；目录删除作为整项展示。未版本控制项目可勾选并自动添加，缺失、冲突项目展示处理原因并禁止勾选。大量目标使用程序目录中的临时目标文件，避免 Windows 命令行长度限制；目标文件按 SVN 所需的本机编码写入，超出编码的名称明确拒绝，不替换字符。临时目标与说明文件最终删除。
14. **本地新建。** 三种浏览区域接入右键新建，树节点右键不提前导航或查询服务器。文本提供简单有效初始内容，Office 由代码直接生成有效的文档包，新建菜单仅保留直接创建的文件类型。新建默认可选本地 SVN 添加、不提交；失败时保留文件。保护同名项目、非法名称、链接 / 元数据 / 嵌套工作副本。创建后立即选中并更新本地状态，不更新服务器检查时间；未访问目录使用明确的本地预览标记，后续主动导航再补全远端列表。抑制本次创建的延迟文件监视通知，之后真实编辑仍正常触发刷新。
15. **删除确认与进度。** 删除确认在启动任务之前显示，等待确认不显示操作进度、不启动计时，取消不执行删除或显示完成。确认提示区分本地新增和已有版本控制的项目，明确新增项目先备份、本地文件不进入回收站、已有服务器内容提交后才删除。已有版本控制的项目继续使用普通 SVN 删除，保留本地修改 / 未版本控制内容保护；操作后的局部刷新规则保持不变。
16. **空白处提交当前目录。** 列表 / 卡片空白处右键显示“提交当前目录…”，无需选择项目即可进入当前目录及其子目录的变更勾选窗口；名称 / 状态筛选不缩小该范围。右键项目显示“提交所选…”，继续使用原来的所选范围。未关联工作副本的在线浏览仍禁止提交。
17. **提交时自动添加。** 未版本控制目录会展开后代，并保留客户端 / 继承全局忽略规则；链接、元数据和嵌套工作副本不自动添加。未版本控制项目默认显示、不勾选，支持全选及分类选择；隐藏时取消对应勾选。点击提交后重新校验本地状态，使用明确目标及空深度添加勾选项目，再在同一次提交中提交勾选变更。未勾选子项保持原状。新增父目录自动联动，缺失 / 冲突继续禁止提交。提交窗口增加地址、扩展名、属性状态和本地锁定人；失败或取消后已完成的添加保留供重试，取消窗口无添加副作用。
18. **操作弹窗与进度统一。** 操作中的输入、选择、确认、提交及文件夹选择统一经过弹窗服务，等待时隐藏进度区域并暂停计时，操作锁继续保留；确认后恢复实际任务的进度，取消不显示完成。提交列表读取与实际提交使用独立阶段，提交窗口等待期间隐藏进度，点击提交后重新计时。覆盖打开、历史比较、撤销、移动、锁定、属性、导出、检出、关联、分支、切换和合并均接入；结果查看窗口继续沿用非模态流程。
19. **提交说明可选。** 提交窗口和创建分支 / 标签均标注“提交说明（可选）”；只要勾选了可提交项目，空说明或仅输入空白也可提交。界面及后台取消非空校验，仍使用说明文件传递原始内容，不填充默认说明；未选项目、缺失 / 冲突及新增父目录依赖校验保持有效。
20. **删除本地新增。** 按最新本地 SVN 状态区分未版本控制 / 忽略项目、已添加但未提交项目和已有版本控制项目。前两类先备份原始内容，未版本控制项目直接删除，已添加项目使用仅限新增目标的 `svn delete --force` 取消添加并删除；已有服务器项目仍使用普通删除。重叠范围去重，不删除打开的根目录、范围外路径、元数据、链接或嵌套工作副本。备份异步执行，失败或取消保留原文件及已完成备份；删除前再次校验状态，避免长时间备份后使用过期的分类。混合选择先处理已有版本控制项目，遇到修改保护时保留本地新增项；完成后仅刷新相关目录。
21. **空悬停提示。** 文件列表行、提交列表及复选框、状态栏、读取状态和进度文字共用文本提示转换器。空值、空字符串或仅含空白的说明转为 `null`，不再创建空提示框；有内容的说明保持原文，文件锁定信息等正常提示继续显示。
22. **目录树精简。** 无差异目录省略“已检查项无差异”副标题并折叠其占用空间，悬停提示也只显示目录名称；有差异时保留统计信息，未检查 / 未关联的说明继续显示。仅调整树的展示，差异判断、刷新和缓存内容保持不变。
23. **状态标签配色。** 主状态各用一组浅色底、深色文字和细边框，一致为绿、服务器更新为蓝、本地修改为橙、本地删除为砖红、双方修改为紫、未下载为灰蓝、缺失为棕、新增为青蓝、服务器删除为玫红、冲突为红；未检查使用中性灰色。列表 / 卡片共用样式，保留状态文字和浅色行选择。
24. **自动附带 SVN。** SVN 1.14.5 x64 的命令行客户端、依赖 DLL、OpenSSL engine、语言文件和许可证固定保存在源码的 `vendor/Subversion/win-x64/`，编译时自动校验并打包，缺失文件会报告构建错误。同时附带 SVN 所需的三个 Visual C++ 可再分发 DLL，不包含 .NET 运行时。运行时从 EXE 同级的 `Tools/Svn/` 使用释放后的内置客户端，有效自定义路径优先，迁移后失效的路径回退到内置版本；应用数据仍保存在 EXE 同级目录。
25. **单 EXE 发布。** 应用 DLL 与调试符号合并进 EXE，SVN 全套依赖压缩嵌入核心程序集，发布时只输出一个 EXE，不包含 .NET 运行时。首次执行 SVN 命令前在后台释放到 EXE 同级的 `Tools/Svn/`，后续启动校验后复用。依赖不完整 / 内容变化时先完整释放并校验，再整体替换；旧客户端目录保留在 `Backups/SvnClient-…/`，取消或失败清理暂存目录并保留已有内容。进程内、进程间均对安装互斥；自定义有效客户端不触发释放。升级旧版时，在新目录不存在的情况下自动将已识别的同级 `Svn/` 整体迁移到 `Tools/Svn/`；额外文件一并保留，若新旧目录同时存在则保留旧目录，不覆盖新目录。
